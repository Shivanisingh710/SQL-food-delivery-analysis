# Online Food Delivery Data Analysis Using SQL

## Project Overview

This project focuses on performing advanced SQL analysis on an online food delivery dataset containing customer, order, restaurant, and menu information.

The objective of this project is to solve business-driven analytical problems using SQL and extract meaningful insights related to customer behavior, restaurant performance, ordering patterns, and menu trends.

The analysis involves complex SQL logic, multi-table relationships, and advanced query-building techniques to answer real-world business questions.

---

## Dataset Information

The dataset consists of the following tables:

* **Customers** – Customer-related information
* **Orders** – Order details and transaction records
* **Restaurants** – Restaurant-related information
* **Menu** – Food items and pricing details

---

## Objectives

This project aims to:

* Analyze customer ordering behavior
* Identify restaurant performance trends
* Explore ordering and menu patterns
* Solve business-oriented analytical questions using SQL
* Generate meaningful insights from structured data

---

## SQL Concepts & Techniques Used

The project demonstrates practical implementation of advanced SQL concepts, including:

* Joins (Inner Join, Self Join)  
* Subqueries & Correlated Subqueries
* Window Functions
* LEAD() & LAG()
* Ntile
* Running Totals / Running Sales Analysis
* Views
* Aggregate & Analytical Functions
* GROUP BY, HAVING, ORDER BY
* Ranking Functions (RANK, DENSE_RANK, ROW_NUMBER)
* Complex Conditional Logic
* Multi-table Data Analysis
